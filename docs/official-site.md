# 公式サイト（minatocrew.com）の調査

> 2026-09-28 に確認。WordPressのサイト。サイト名「Minato イベント」。
> ここに書いたページの内容は公開情報。

## サーバー

- minatocrew.com は Xserver（sv16086.xserver.jp）で動いている
- `event.minatocrew.com` もすでに同じサーバーを向いている（DNSは設定済みとみられる）。ただしSSL証明書がなく（`*.xserver.jp` の証明書が返る）、httpでは403。サブドメインのサイトはまだ作られていない
- このサーバーがYumaさん契約のXserverと同じかは要確認。同じなら、サーバーパネルでサブドメインを追加して無料SSLを付けるだけで公開できる

## ページと、アプリで置き換えるもの

| ページ | 今の中身 | アプリでの扱い（案） |
|---|---|---|
| /registration/（イベント予約フォーム） | Googleフォームを埋め込み | 掲示板の申込フォームに置き換え、このページからはアプリへリンク |
| /schedule/（イベントスケジュール） | Googleカレンダーを埋め込み | 掲示板の回の一覧に置き換え（Googleカレンダー連携が要らなくなる） |
| /event-lists/（MINATOイベント内容） | イベントの考え方と種類の紹介（回の一覧ではない） | そのまま残し、「イベント一覧を見る」をアプリへつなぐ |
| /contact/（お問い合わせ） | Contact Form 7（氏名・メール・件名・内容・同意） | 回についての問い合わせはアプリへ。コラボ依頼など一般の問い合わせを残すかは要相談 |
| /crew/（クルー募集） | クルー申込フォーム（Contact Form 7：氏名・メール・生年月日・地域・電話・初回連絡の希望方法・コメント・3つの同意） | 今回の範囲に入れるかは要相談 |
| /crew-cancellation-policy/ | 解約はGoogleフォームで受付 | 同上 |
| /faq/、/privacy-policy/、/crew-terms-of-service/、/crew-policy/ | 規約類 | アプリの申込フォームからリンクする |

## 料金とクルー

- **MINATOクルー**：月額5,500円（税込）、クレジットカードの自動更新
- **クルーのイベント特典**：オフラインイベントの参加費が3,000円引き、オンラインイベントは無料（アーカイブ視聴可）
  - シートの料金5,000円／2,000円は、一般とクルーの差（3,000円）と合う
- **支払い**：イベントは事前入金制。入金後の返金は原則なし（よくある質問より）
- サービス欄に「WAKU-MEカード」がある。シートの「わくMe進捗」との関係は要確認

## イベントの打ち出し方（掲示板の文章に使える）

/event-lists/ で大事にしていること：

1. 初参加・1人参加が多い
2. 勧誘目的は一切NG
3. 遊び × 学び × 仲間
4. 自分らしさを大切に

開催イベントとして挙げているもの：運動会・文化祭・マルシェ（大型）、朝活・パートナーシップ会・女子会・リトリート（定期）、花見・夏祭り・ハロウィン・クリスマス（季節）。

新規の人が不安に思うこと（1人で行っていいか、勧誘されないか）に先に答えているので、掲示板の回のページにも同じ内容を載せると新規集客に効く。

## デザイン

- フォント：Noto Sans JP（400・600）
- 色：紺 `#000c2e`、オレンジ `#dd8b0f`。アクセントに淡いピンク `#ffdfdf`・`#ff99b8`、水色 `#ccf4ff`、黄色 `#fff799`
- 錨（⚓）のモチーフ。「港＝旅立つ場所であり、帰ってくる場所」というコンセプト
- 公式LINEとInstagram（@minato_community）へのリンクが全ページにある

## プライバシーポリシーで気になる点

アプリで顧客を管理し始める前に、運営側で見直してもらうとよい（法的な判断は専門家に）。

- 問い合わせ先のメールアドレスが仮のまま（`xxxx@example.com`）
- 電話番号を「任意」としているが、イベントの申込では必須にしている
- SNSアカウント、参加履歴を顧客リストとして持つこと、出禁の管理、次回の案内に使うことが、取得する情報・利用目的に書かれていない
