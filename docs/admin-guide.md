# 管理画面の使い方

運営メンバー向けの手引き。スマホでも使える。URL は `https://event.minatocrew.com/admin`（本番公開後）。ローカルは `http://localhost:8080/admin`。

## ログイン

- アカウントは1人ずつ発行される（共有しない）。ログインIDとパスワードは発行した人（オーナー）から受け取る
- パスワードを5回続けて間違えると15分止まる。急ぐときはオーナーに「パスワードの再設定」を頼む（再設定すると止まっている状態も解除される）
- 8時間操作しないと自動でログアウトする

## トップ

- 「これからの回」に直近の回が出る。「当日受付」ボタンで受付画面に直接行ける
- 下のメニューから各機能へ

## 回（イベントの各回）

- **新しい回**：形式（リトリート／女子会／自己啓発／合コン）を選ぶと、その形式の既定の支払い方法（前払い／当日払い）が入る。タイトル・開始日時・参加費は必須
- **定員**：空欄なら上限なし。男女別の定員・料金は合コンなど必要なときだけ入れる
- **キャンセル期限**：前払いの回で空欄のまま作ると、開始の7日前が入る（今のキャンセルポリシーに合わせた既定）
- **状態**：下書き → 募集中 → 締切 → 終了。中止にもできる。「募集中」が掲示板に出る状態（掲示板は準備中）
- **複製**：回の詳細の「複製」を押すと、同じ内容の下書きができる。第n回は +1 され、日時はそのままなので直して保存する
- 回の詳細では、申込者の一覧・入金・到着の状況が見える。「詳細」から参加費（クルー割引など）や入金確認を変えられる

## 申込の手入力

スタッフの声かけ（LINE・口頭）で決まった人を登録する。回の詳細 → 「申込を追加」。

1. 名前・フリガナ・電話番号で顧客を探す。いれば「この人を申し込む」
2. いなければ「新しい顧客として登録して申し込む」。電話・メール・名前が既存の顧客と同じときは警告が出るので、同じ人ならその人を選び直す
3. 参加費（既定は回の参加費。男女別料金があれば性別で変わる）、どこで知ったか、メモを入れて「申込を追加する」
4. 定員に達していると自動で**キャンセル待ち**になる。定員を超えて入れるときは「定員を超えて申込にする」にチェック
5. **出禁**の人は警告が出る。それでも入れるときはチェックを入れる

- 前払いの回では、入金を確認したら「入金を確認済み」を付ける（申込時か、申込の詳細から）
- キャンセルは申込者一覧の「キャンセル」。戻すときは「申込に戻す」（定員内なら申込、いっぱいならキャンセル待ちのまま）
- キャンセル待ちの人を入れるときは「繰り上げ」

## 当日受付

回の詳細 → 「当日受付」（トップの「これからの回」からも行ける）。

- 来た人の「到着」を押す。当日払いの人は金額（既定は参加費）と支払い方法を確かめてから押す。前払い済みの人は金額欄が出ない
- 押し間違えたら「取り消し」
- 人が多いときは名前で絞り込む
- 申込にない人が来たら「飛び入りの人を追加」
- キャンセル待ちの人が来て「到着」を押すと、そのまま申込（参加）になる
- 2人で同時に受付をしても、同じ人が二重に記録されることはない

## 顧客台帳

- 名前・フリガナ・電話番号・メール・SNSで検索できる。数字だけ入れると電話番号、@ があるとメールで探す
- 顧客の詳細で、連絡先・参加履歴・運営メモ・移行元のデータ（今のスプレッドシートの行）が見える
- **案内メールの同意**：本人が同意したときだけチェックを入れる。同意した日時と、外した日時を記録する（法律上必要）
- **出禁**：詳細の下の「出禁にする」。理由は運営向けのメモ。出禁の人は一覧・受付・申込で赤い印が出る。解除もできる
- **名寄せ**：顧客台帳の「名寄せ」に、同じ電話番号・同じメール・同じ名前の組が出る。「残す顧客」を選んで「まとめる」と、ほかの人の申込が残す人に付け替えられ、ほかの人は消える。同姓同名の別人もいるので、フリガナ・電話・参加履歴を見て判断する。同じ回に両方の申込がある組はまとめられない（先にどちらかをキャンセルする）
- 顧客の詳細にも「同じ人かもしれない顧客」が出るので、そこからもまとめられる

## 会計

- 「会計」に回ごとの収入・経費・主催分・収支の一覧が出る
- **収入** ＝ 前払いで入金確認済みの参加費 ＋ 当日受付で記録した入金
- **収支** ＝ 収入 − 経費 − 主催分
- 回の会計で経費を項目ごとに入れる（項目は形式ごとの候補から選べるし、自由に書ける）。主催分もここで変えられる
- 収支表への書き出しは次の段階

## 設定

- 「どこで知りましたか」の選択肢を増やせる。使わなくなったものは「表示」を外す（過去の記録は残る）。順の数字が小さいほど上に出る

## 運営メンバー（オーナーだけ）

- メンバーの追加、表示名・権限・有効／無効の変更、パスワードの再設定
- パスワードを空のまま追加・再設定すると自動で作られ、次の画面に1回だけ表示される。本人に安全な方法で伝える
- 自分の権限は自分では変えられない。辞めた人は「無効」にする（消さない。記録に名前が残る）
- 全員ログインできなくなったときは、サーバーで `php bin/create-admin.php --reset` を実行してパスワードを再設定する

## 困ったとき

- 「送信できませんでした」と出たら、画面を開いてから時間がたっている。前の画面に戻って読み込み直す
- 「権限がありません」はオーナーだけができる操作
- 画面がおかしい・エラーが出るときは、開発者（Yuma）に画面の写真を送る
