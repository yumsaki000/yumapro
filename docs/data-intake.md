## 全体の流れ

```
公式サイト・こくちーず・Instagram・公式LINE ─ リンク ─┐
                                              ├─→ 掲示板の申込フォーム ─┐
スタッフの声かけ（LINE・口頭） ─────────── 管理画面で手入力 ─┼─→ 名寄せ（顧客） → 回ごとの申込 → 当日受付 → 会計
今のスプレッドシート（最初に1回だけ） ──────── 移行 ─────────┘
```

申込を受ける場所はこのアプリの掲示板に一本化し、集客の窓口（こくちーず、公式サイト、SNS）からはそこへリンクする。

## 申込の入口

### 掲示板の申込フォーム

> 2026-09-29 作成済み（`src/Applications.php`、`src/Web/BoardController.php`）。以下の設計どおりに動く。同意文・確認メールは管理画面の設定で変えられる。

- 今のGoogleフォームの項目と同意文を引き継ぐ（項目の一覧は [official-site.md](official-site.md) の「イベント予約フォーム」）
- メールアドレスは必須にする（今は任意で5%しかない）。申込後に予約確認メール（会場の詳細・振込先・キャンセルポリシー）を送る
- 「案内メールを受け取る」は任意の同意欄にする。同意した日時を記録し、案内メールには配信停止のリンクを付ける
- 「どこで知りましたか」の選択肢は管理画面で増減できるようにする。初期値は今のフォームの6つに、シートの集客媒体（つなげーと、X、Threads、他のMINATOイベント、GOAL-B、フレバブ、可能性大学、アオイエシェアハウス、ココナラなど）を足したもの
- 支払いは今と同じく事前の銀行振込。入金確認は運営が管理画面で付ける（今は公式LINEに入金額を送ってもらって確認している）
- 会場の詳しい場所は、申込が確定した人にだけ見せる
- 窓口ごとにリンクを分けて（例：`?from=kokuchpro`）、どこから来たかを自動で記録する
- 定員に達したら自動で締め切り、キャンセル待ちに回す（自前のフォームなのでアプリ側でできる）

### 管理画面での手入力

- スタッフの声かけ（LINE・口頭）で決まった人を、スタッフがスマホから登録する
- 今の「声掛けリスト入力フォーム」「出禁リスト報告フォーム」の代わり

### 今のスプレッドシートからの移行（最初に1回だけ）

- 声掛けリスト（約600人）→ 顧客
- フォームの回答（415件）と回ごとのシートの進捗 → 参加履歴。引き継ぐかはヒアリング（4-4）で確認
- 出禁リスト → 出禁の印
- 移行前に「新規◯件・名寄せ候補◯件」を見せて確認してから確定する。元の行は `customers.legacy_data` にそのまま残す
- 顧客（声掛けリスト＋フォームの回答の連絡先）の移行スクリプトは作成済み。手順は [migration.md](migration.md)

## 名寄せ（同じ人を1件にまとめる）

申込・手入力・移行のたびに、次の順で既存の顧客と照らし合わせる。今の申込は電話番号が必須で、メールは5%しかないため、電話番号を先にする。

1. 電話番号が一致 → 同じ顧客（ハイフンや空白を除いた数字で比べる）
2. メールアドレスが一致 → 同じ顧客（大文字・小文字、前後の空白は無視）
3. 名前だけが一致 → 自動ではまとめない。「同じ人かも」の候補として出し、運営が手で統合する
4. どれにも当たらない → 新しい顧客として登録

- 名前は全角・半角と空白をそろえてから比べる
- 手で統合したときは、申込をまとめ先の顧客に付け替えて、もう一方は消す

## 出禁チェック

今のApps Scriptと同じ判定にする（[current-sheet-analysis.md](current-sheet-analysis.md)）。

- 電話番号・メール・SNSのどれかが一致 → 「確定」。運営に通知し、申込に印を付ける
- 名前（空白除去・3文字以上）だけが一致 → 「要確認」。フリガナの一致も表示する
- スキップの印が付いた人は除外する
- 同じ電話番号から1分以内の再送信は受け付けない
- 2026-09-29 作成済み：出禁リスト画面（登録・解除・検索）、申込フォームでの自動判定（確定はキャンセル待ちに止める、要確認は印）、確認待ちの処理（別人／同じ人）、運営への通知メール、今のシートからの移行（`bin/import-banned.php`）。手入力では出禁の人に警告を出し、チェックを入れないと登録できない

## クルーと講座（2026-09-29 追加）

- クルーの申込は募集ページ（`/crew`）から。名寄せは申込フォームと同じ（電話→メール）。承認は管理画面で行い、月額の支払いはアプリの外
- 参加者のログインはメールで届くリンク（`login_tokens`。30分・1回だけ）。個人専用URLを開いたときもログイン状態になる
- 講座は `courses`／`lessons`／`course_purchases`。見られるかの判定は `Courses::canView()`（お試し → 全員 → ログイン → クルー → 購入の順）
