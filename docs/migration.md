# 今のスプレッドシートからの移行

> アプリを使い始める前に1回だけ行う。移すのは顧客（声掛けリスト）と連絡先（フォームの回答）。
> 回ごとの参加履歴を移すかはヒアリング（4-4）の回答を見てから決める。

## 何がどこに入るか

| 移行元 | 移行先 |
|---|---|
| 声掛けリストの「番号」 | `customers.legacy_no`（何度流しても顧客が増えないためのキー） |
| 名前・カタカナ・性別・集客媒体・備考 | 顧客の 名前・フリガナ・性別・最初に来たきっかけ・運営メモ |
| 紹介者・仕事内容・クルー・わくMe など | `customers.legacy_data` にそのまま残す（使い道がヒアリングで決まったら、正式な項目に移す） |
| フォームの回答の 電話番号・メール・SNS | 同じ名前の顧客に付ける。何度も申し込んでいる人は新しい回答を優先 |

- 同じ名前の顧客が複数いるときはフリガナで見分け、それでも決まらなければ連絡先を付けない
- 同じ名前・同じ電話番号の人は自動でまとめず、「同じ人かもしれない組」として出す（移したあと管理画面で確認）
- 声掛けリストにいない人（フォームにだけいる人）は移さない
- もう一度流すと、名前・フリガナ・性別・集客媒体・備考はCSVの内容で上書きされる（管理画面で直した内容は消える）。連絡先は空のときだけ埋まる。移し終えて管理画面で使い始めたら、もう流さない

## 手順

1. Googleスプレッドシート「【2026年★】イベント集客管理表」で、「声掛けリスト」と「フォームの回答」をそれぞれ開き、「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存する
2. CSVを `storage/import/` に置く（個人情報なのでGitには入らない設定になっている）

   ```sh
   mkdir -p storage/import
   # 例：storage/import/koekake.csv と storage/import/responses.csv
   ```

3. まず確認だけ流す（DBには書かない）

   ```sh
   make import-customers LIST=storage/import/koekake.csv RESPONSES=storage/import/responses.csv
   ```

   人数・連絡先を付けた人数・同じ人かもしれない組が出る。名前の一覧も見るときは `VERBOSE=1` を付ける

4. 問題なければ書き込む

   ```sh
   make import-customers LIST=storage/import/koekake.csv RESPONSES=storage/import/responses.csv COMMIT=1
   ```

5. 終わったら `storage/import/` のCSVを消す

本番（Xserver）では、SSHで `php bin/import-customers.php <声掛けリストのCSV> --responses=<フォームの回答のCSV>` を同じ順に実行する。

## 2026-09-28 に受け取ったデータで試した結果

ローカルで確認し、終わったあとDBとCSVは消した。

- 顧客598人（男性376・女性222）。フリガナなし3人
- フォームの回答195人のうち189人に連絡先を付けた（電話189・メール18・SNS 86）
- 同じ名前の顧客が複数いて付けなかった人1人、声掛けリストにいない人5人
- 同じ名前の組5組、同じ電話番号の組0組
- 2回続けて流しても、2回目は「変更なし598人」で重複しない
